# ⚡ لقطة // LOO2TAA — رادار صفقات الجيمنج والبي سي في مصر

منصة رصد سيبرانية مستقلة لمجتمع الجيمرز والشباب في مصر، مخصصة لتتبع ومقارنة أسعار عتاد الألعاب، كروت الشاشة، أجهزة البلايستيشن، شاشات الـ 165Hz، ولابتوبات الجيمنج في المتاجر الرسمية (أمازون مصر، نون).

## 🚀 المميزات الأساسية
- **رادار مسار السعر لآخر 90 يوماً:** رسم بياني تفاعلي يوثق رحلة السعر وكشف العروض والخصومات الوهمية.
- **ختم اللقطة القياسية:** رصد الهاردوير الذي يسجل أدنى قاع تاريخي في السوق المصري.
- **تحليل العتاد بالذكاء السيبراني:** ملخص سريع لأداء الـ FPS، كفاءة التبريد في صيف مصر، ونبض مجتمع الجيمرز.
- **ثيم سايبر بانك مصري:** واجهة تفاعلية مظلمة مع تأثيرات نيون زرقاء قاهرية (`#00f0ff`) وتصميم هولوجرامي متجاوب مع الموبايل.
- **عتادك المحفوظ (Favorites):** قائمة أمنيات محلية بدون الحاجة لتسجيل حساب.

## 🛠️ التقنيات المستخدمة
- **Next.js 16 (App Router & React 19)**
- **Tailwind CSS v4**
- **Lucide Icons**
- **Recharts (منحنيات الأسعار التفاعلية)**
- **TypeScript**

## 💻 التشغيل المحلي
```bash
npm install
npm run dev
```
افتح [http://localhost:3000](http://localhost:3000) في المتصفح.
